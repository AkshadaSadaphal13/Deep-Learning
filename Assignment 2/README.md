# Assignment 2 - MLP Classification using Iris Dataset

## Aim

To design and implement a Multilayer Perceptron (MLP) for classification of the Iris dataset and evaluate its performance using accuracy and a confusion matrix.

## Dataset

The Iris dataset contains 150 samples with four input features:

- Sepal length
- Sepal width
- Petal length
- Petal width

The dataset contains three classes:

- Setosa
- Versicolor
- Virginica

## Technologies Used

- Python
- Scikit-learn
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook
- VS Code

## Steps Performed

1. Loaded the Iris dataset
2. Explored the dataset
3. Visualized the dataset
4. Split the dataset into training and testing sets
5. Standardized the input features
6. Designed an MLP classifier
7. Trained the MLP model
8. Generated predictions
9. Evaluated the model using accuracy
10. Generated and visualized a confusion matrix

## MLP Architecture

- Input features: 4
- Hidden Layer 1: 10 neurons
- Hidden Layer 2: 10 neurons
- Output classes: 3
- Activation function: ReLU
- Optimizer: Adam

## Evaluation

The model performance was evaluated using:

- Classification Accuracy
- Confusion Matrix

## Result

The MLP model successfully classified the three Iris flower species with high classification accuracy. The confusion matrix was used to visualize correct and incorrect predictions for each class.
