# Assignment 1 - TensorFlow/Keras Data Preprocessing

## Aim

To install and configure TensorFlow/Keras and perform data preprocessing, normalization, train-test splitting, and data visualization using a sample dataset.

## Dataset

Fashion-MNIST dataset provided by TensorFlow/Keras.

The dataset contains 28 × 28 grayscale images belonging to 10 different clothing categories.

## Technologies Used

- Python
- TensorFlow
- Keras
- NumPy
- Pandas
- Matplotlib
- Scikit-learn
- Jupyter Notebook
- VS Code

## Tasks Performed

1. Installed and configured TensorFlow/Keras
2. Loaded the Fashion-MNIST dataset
3. Performed data preprocessing
4. Normalized pixel values from 0-255 to 0-1
5. Performed train-validation-test splitting
6. Visualized sample images
7. Built a simple Keras neural network
8. Trained and evaluated the model
9. Visualized training and validation accuracy

## Files

- `Assignment_1.ipynb` - Complete assignment notebook
- `README.md` - Project description

## Result

The Fashion-MNIST dataset was successfully loaded, preprocessed, normalized, split into training/validation/testing sets, and visualized using Python, TensorFlow/Keras, and Matplotlib.
